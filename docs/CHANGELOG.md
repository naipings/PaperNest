# 更新记录

## 0.1.10 - 2026-08-14

### 文档与代码清理

- 重写 README、开发文档与调研文档，去除冗余的防御性表述。
- 移除 PDF 导入时的 SHA-256 去重门禁；重复检测保留 DOI 与标题匹配。
- 删除 `sha2`、`hex` 依赖及 `idx_papers_sha` 唯一索引。

## 0.1.9 - 2026-08-04

### 修复与优化

- 连续 PDF 阅读由手工画布/文本层拼接改为 PDF.js `PDFPageView`，统一高 DPI 渲染、文本选择、缩放与批注坐标。
- 新增左 Ctrl + 鼠标滚轮缩放，普通滚轮保持下拉阅读。
- 优化论文详情的「移入回收站」按钮位置。
- 修复表格固定列在横向滚动时表头与数据列错位的层级问题。
- 修复单页批注页码控件重叠，以及高亮、下划线工具未生效的问题。

### 新增

- 论文表格支持单选、多选、全选与批量移入回收站。
- 本地 LibreTranslate 脚本改为可迁移部署：使用 `%LOCALAPPDATA%\PaperNest\LibreTranslate`，并提供首次安装脚本。
- 重建 README、开发文档与更新记录为 UTF-8 中文文档。

## 0.1.8 - 2026-08-04

- 增加 LibreTranslate 兼容翻译：选中术语或写作句子时可翻译后收录。
- 增加连续下拉式 PDF 阅读、文本选择、高亮、下划线和术语/佳句快捷操作。
- 增加 PDF 框选框架图和从剪贴板粘贴框架图。

## 0.1.7 - 2026-08-04

- 提升全局字体与表格字体大小。
- 本地知识树支持滚轮缩放、拖动画布、节点单击查看摘要和双击定位论文表格。
- 节点采用作者加年份标签，颜色表示领域，大小和透明度表达本地相似关系强度。

## 0.1.6 - 2026-08-03

- 增加 OCR、在线 Crossref 元数据补全、LLM 导入分析和本地知识树。
