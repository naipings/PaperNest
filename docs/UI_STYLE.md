# 界面风格

PaperNest 使用固定侧栏、分栏列表、正文与工具栏组织桌面界面。

| 元素 | 规则 |
|---|---|
| 壳层 | 全高平铺；导航宽 200px，收起后 56px；导航项高 42px、间距 3px，Logo 使用主题强调色底色；面板以分隔线划分 |
| 配色 | 主题决定配色，公共布局位于 src/desktop.css；控件使用实色与轻边框 |
| 控件 | 按钮高度约 36px，圆角 4–5px；选中、悬停与键盘焦点分别可辨 |
| 字体 | 沿用 0.2.54 的 Segoe UI Variable / Segoe UI / Microsoft YaHei UI 系统字体；导航 15px、600 字重，操作 14px、精读正文 16px / 1.8；正文常规、标题半粗 |
| 页头 | 功能标题、必要说明与右侧操作；文字陈述当前功能和状态 |
| 论文库 | 概览沿用 0.2.52 的标题、三项统计卡片和未读概况布局；表格主标题 600 字重，副标题常规，横向与列分隔线均保留；窄窗保存和刷新使用带名称的图标 |
| 精读 | 任务列表与正文分栏；常用操作为复制和对照阅读，原文、文件夹、重新生成放在更多菜单；正文避免重复显示论文标题 |
| 追问 | 问答滚动，输入区位于底部；空状态和进度使用直接说明 |
| 对照阅读 | PDF 工具栏按面板宽度换行；证据定位与批注保留原有行为 |
| 对话框 | body portal 居中显示，8px 圆角；Tab 限于当前窗口，Escape 关闭最上层窗口，关闭后焦点返回入口 |
| 合并导出 | 确认窗口说明范围与保存位置；取消不写入，确认后显示“导出中…”并禁用入口，结束后显示路径或错误 |
| 调研阅读工作区 | 标题与操作独立于研究问题，操作按钮固定 36px；页头和轮次选择保留，报告正文独立滚动，切换轮次回到顶部 |
| 阅读边界 | 精读与 Skill 文档使用主题面板、1px 细边框与阅读留白，外侧为柔和底色；文档宽度最多 940px，正文最多 780px，纯黑文档背景为 #000 |
| 选中反馈 | 导航选中项使用主题色混合背景和细边界；文件夹与任务列表使用同色系背景；调研、精读页签使用有边界的选中面板 |
| 搜索框 | 图标、输入和快捷键位于同一边界内，文字 14px；焦点高亮整框，输入层不重复画框；独立搜索输入使用同样的高度与焦点色 |
| 生成步骤 | 进度步骤 14px、500 字重，窄窗两列，常规窗口四列 |
| 雷达筛选 | 显示当前兴趣匹配数和采集数；筛选为零时说明原因并提供完整榜单入口；默认筛选偏好沿用用户设置 |
| 任务与日历 | 今日、逾期、完成计数与清单、日历并列；日期文字随主题保持可读 |

## 主题

在「设置 → 个人资料 → 主题」选择并保存。

| 选项 | 实现 |
|---|---|
| 标准 · 跟随系统 / 浅色 / 深色 | styles.css + reference-theme.css |
| 紫色 · 跟随系统 / 浅色 / 深色 | lilac-dashboard-theme.css |
| 蓝灰 · 跟随系统 / 浅色 / 深色 | mist-dashboard-theme.css |
| 苔绿 · 跟随系统 / 浅色 / 深色 | willow-dashboard-theme.css |
| 纯黑 · 夜间 | black-theme.css；主体与阅读背景 #000，控件深灰，正文浅灰 |

纯黑主题保存为 profile.visualTheme = black、profile.theme = dark，重启后恢复。侧栏切换明暗时进入标准浅色主题。PDF 默认反色显示，阅读工具栏「PDF 原色」可临时切回原色；该变化仅影响显示。

PDF.js 官方样式经 Vite/PostCSS 限定在 .continuous-page-host 内。精读面板内部样式在 components/deepread/DeepRead.css；公共桌面样式与主题依次覆盖布局和颜色。

当前外观实施：[导航、论文库概览与表格](design/0258-ui-corrections.md)；基础规范：[0.2.54 基础调整](design/0254-refinement.md)。

阅读区布局与验证：[0.2.59 阅读工作区](design/0259-reading-workspace.md)。

调研操作按钮固定 120 × 36 CSS px、14px 字号，允许按窗口宽度换行。精读页头显示图标、标题和任务数；新建精读的文件夹菜单显示父子路径并限制高度。任务列表和详情均提供删除入口，经过两次独立确认执行永久删除。实施与验证：[0.2.61 精读修复](design/0261-deepread-repairs.md)。
