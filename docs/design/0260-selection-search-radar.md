# 筛选状态、搜索与选中反馈（0.2.60）

## 要求与步骤

1. 核对雷达本地快照和兴趣筛选结果，明确区分采集为空与筛选后为空；保留用户保存的默认筛选偏好，提供显式查看完整榜单入口。
2. 导航、列表和文件夹选中背景使用主题色混合面板底色，提高辨识度。精读和调研页签使用带边框的选中面板。
3. 搜索框统一图标、输入文字与焦点边界。组合搜索框在外层显示焦点，输入层不再单独画框；占位文字简短，搜索范围通过名称和提示保留。
4. 精读生成步骤使用 14px、500 字重，展开区按窗口宽度采用四列或两列。
5. 验证雷达筛选开关、空结果入口、实际榜单数据、搜索输入、主题和窗口尺寸，运行回归并打包。

## 调查与依据

- 本地 2026-10-15 快照：热点 30 篇、新稿 50 篇，应用当前兴趣条件后均为 0。10-14 为热点 22、新稿 50，过滤后均为 0；10-13 新稿原始数量为 0，应显示采集为空。
- 当前关键词为 agent memory、agent skill；订阅 cs.AI、cs.IR、cs.LG、cs.MA。后端按关键词短语命中并同时满足订阅领域筛选，前端旧空白状态容易被理解为采集失败。
- 修复手动筛选状态仍受初始默认值影响、导致界面标签与请求状态不一致的问题。
- [Carbon Search](https://carbondesignsystem.com/components/search/usage/)：图标、输入文本和完整搜索框的焦点状态。
- [Carbon Tabs](https://carbondesignsystem.com/components/tabs/usage/)：明确区分选中、悬停和聚焦状态，以面板边界组织同一上下文中的内容。
