# 桌面界面与纯黑主题

## 当前要求

- 精读、阅读台及相关界面使用紧凑的桌面布局，减少卡片嵌套、渐变、阴影、大圆角和装饰性标签。
- 页面文字使用功能名称、数据和直接操作说明。
- 新增「纯黑 · 夜间」主题，应用主体使用 `#000`，控件用灰色边框和浅灰文字区分，PDF 页面降低亮度。
- 保留现有资料与操作流程，完成桌面实测并生成新版安装程序。

## 实施与验收

1. 统一公共壳层、导航和按钮；精读页采用列表与正文分栏，工具栏按使用频率组织。
2. 修改精读、追问、论文库等页面中的宣传文案，保留操作所需说明。
3. 接入纯黑主题的选择、保存、重启恢复与明暗切换，检查阅读台、对话框、设置及各主页面。
4. 验证 1100 × 700 和 1440 × 900 的布局、弹窗键盘操作、报告阅读与证据定位；运行测试和生产构建，打包 0.2.54。

验收以实际运行截图、黑色主题计算样式、主题保存与恢复测试，以及生产程序启动结果为依据。

调研参考：[Zotero 阅读器](https://www.zotero.org/support/pdf_reader) 与[资料集合](https://www.zotero.org/support/collections_and_tags)的分栏组织。公共布局使用本项目组件实现。

## 验证记录

- 自动测试：57 个文件、220 项通过。包含主题保存与重开设置恢复、菜单关闭、弹窗焦点循环与嵌套 Escape、现有精读与 PDF 回归。
- Tauri/WebView2 实测：设置保存「纯黑 · 夜间」，重新加载后恢复 black/dark；主体、导航、工作区、设置面板背景均为 `rgb(0, 0, 0)`。
- 纯黑主题已检查论文库、精读、追问、对照阅读、写作、任务日历、知识树、雷达、Skill、文献调研和设置页面；调研轨迹局部颜色与日历日期单独调整。
- 1100 × 700：PDF 面板宽度与滚动宽度均为 440px；追问输入区位于视区内；选篇对话框 880 × 618px，Tab 焦点保留在窗口中。
- PDF：夜间滤镜与原色切换生效；点击证据产生 29 个段落高亮矩形。显示设置不写入 PDF 文件。
- 其余四套配色的浅色/深色均检查布局；复查深色按钮和选中导航的背景图均为 `none`，最小窗口无横向溢出。
- 截图位于 `output/playwright/0254-*.png`，包括浅色精读、纯黑精读、PDF 对照、最小窗口追问/选篇和各页面。

本轮界面测试使用已有报告与 PDF，未发起模型生成和付费追问。
