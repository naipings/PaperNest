# 阅读台便签批注重设计（v0.2.33）

## 目标

对齐 UPDF / Acrobat 的 sticky note 交互：页上常驻小图标，弹窗与图标解耦，黑底编辑卡，放置后回到选择模式。

## 状态

| 状态 | 可见 | 触发 |
|------|------|------|
| idle | 图标 | 默认 |
| hover | 图标 + 只读预览 | 悬停图标（非编辑） |
| open | 图标 + 编辑卡 | 新建 / 双击 / 侧栏 / 右键编辑 |
| selected | 图标高亮 | 单击图标 |

全局同时最多一个 `open`。

## 交互

- 批注模式单击页面 → 创建并 `open`，工具切回「选择」
- **单击图标 → 仅选中**，不打开编辑
- **双击图标 → 打开编辑**
- 悬停 → 只读预览，**图标不消失**
- 编辑卡：黑底白字；底栏 = 色点（仅染图标）+ 字号 + 删除 + 发送
- 发送 / × / 点空白 / Esc → 保存草稿并关闭
- 拖图标 → 改 `geometry.anchor`；拖编辑卡标题 → 仅会话内偏移弹窗
