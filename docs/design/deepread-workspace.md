# 论文精读界面调整

目标：在桌面最小窗口 1100 × 700 和常用 1440 × 900 下，任务、报告、追问与对照阅读保持清晰层级，操作可见，长内容不撑破工作区。

## 实施顺序

1. 运行桌面软件，检查现有报告、追问、选篇和 PDF 对照布局并保存截图。
2. 精读页改为完整页头、任务侧栏和阅读工作区；选篇放入「新建精读」对话框，释放报告宽度与任务列表高度。
3. 整理标题、操作工具栏、八阶段进度、报告排版；追问输入区固定在面板底部，长内容在对应区域滚动。
4. 修复异步切换任务时旧内容覆盖新任务、输入法回车误发送、加载与失败反馈；对照阅读使用面板宽度控制工具栏。
5. 实际操作验证浅色/深色、各主题、最小窗口、长报告、选篇与空状态，运行测试和生产构建，升级版本并打包 NSIS 安装程序。

## 验收标准

- 页面无横向溢出；页头、任务列表、报告和输入区互不遮挡。
- 任务侧栏和报告内容独立滚动，切换任务显示对应报告和加载反馈。
- 选篇、已选、拖放、生成、复制、错误均有可辨识反馈。
- 对照阅读中报告与原文各自滚动，证据跳转与原有批注保持可用。
- 安装包位于 `release/windows/`，记录验证结果和实际未覆盖项。

## 视觉方向

沿用现有主题配色，使用低对比边框、紧凑工具栏、明确的选中态和较宽的正文留白。优先解决阅读任务中的空间分配与反馈。

调研入口：[VibePrompt](https://vibeprompts.dev/) 的应用页头、可收起侧栏与 dashboard 布局分类；[Kyla 提示词库](https://prompt.kyla.cloud/library.html) 的 Dashboard、ReUI 与组件索引。页面结构基于现有 React 组件和主题实现。
