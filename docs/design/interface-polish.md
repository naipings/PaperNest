# 界面字号与层次调整

## 当前要求

- 保留简洁分栏和纯黑主题，参考提供的导航与论文库标题栏截图，细化字号、间距、边框和交互反馈。
- 导航字号由 12px 提高到 14px；按钮、筛选器、表格和辅助信息同步检查，兼顾最小窗口。
- 论文库统计栏通过标题、数字、标签、分隔线明确层次，数字和标签保持间距。
- 改善刷新、选中、悬停、键盘焦点和浮层反馈，保持原有功能路径。
- 参照用户提供的 Codex 字体截图：采用系统无衬线字体，统一 400/500/600 字重，正文 16px / 1.75 行高，标题使用正常字距。

## 实施顺序

1. 调整公共字体与导航尺度，细化标题栏、统计、列表、阅读面板和弹窗的视觉节奏。
2. 检查刷新反馈及筛选菜单的键盘操作，针对具体问题补充回归测试。
3. 使用 Playwright 操作 Tauri/WebView2，检查 1440 × 900 与 1100 × 700、浅色/深色/纯黑主题。
4. 运行测试与生产构建，生成 0.2.55 安装程序并启动发布目录的程序复查。

## 验收

- 导航字体至少 14px；常用操作字体 13px，表格主信息 13–14px，辅助信息至少 12px。
- 标题栏和统计数字对齐、间隔明确；最小窗口无页面横向溢出，工具栏和浮层可用。
- 纯黑主题主体仍为 #000；状态通过颜色、边框和文字共同表达。
- 操作可见反馈、键盘交互和生产版启动检查通过。
