# PaperNest 本地论文库

PaperNest 是面向计算机研究生新手的 Windows 本地论文管理工具。论文表格、PDF 阅读批注、术语学习、写作素材和本地知识树共用同一资料库；本地运行，无账户与云同步。

## 快速开始

### 1. 首次启动

1. 安装并启动 PaperNest。
2. 首次启动时选择资料库目录。建议选择容量充足、会定期备份的非系统盘。
3. 程序会在该目录创建 `library.db`、`pdf/originals`、`figures` 和 `backups`。请不要手动移动其中的单个文件。

### 2. 导入与阅读

1. 在论文库右上角点击「导入 PDF」，选择一个或多个 PDF；也可导入 BibTeX/RIS。
2. 补充中英文标题、作者、领域、标签和一句话总结。
3. 单击论文打开右侧详情；双击或点击 PDF 图标进入阅读台。
4. 普通滚轮上下阅读；按住左 Ctrl 再滚动可缩放。

### 3. 批注与知识沉淀

1. 鼠标拖选英文词语或句子，使用「高亮」「下划线」「收为术语」或「加入写作库」。
2. 术语和佳句会保留来源论文和页码，可从资料库回到原页。
3. 导出批注时生成带可见批注的新 PDF 副本。

### 4. 整理、备份与可选服务

- 使用领域、标签、阅读状态、保存视图和全局搜索定位论文。
- 勾选表格第一列可批量移入回收站；回收站中可恢复或永久删除。
- 定期在「设置」中创建完整备份。
- 需要翻译时，首次使用输入 LibreTranslate 兼容地址；免费本地方案见下文「翻译服务与换机」。

## 核心流程

```text
导入 PDF / BibTeX / RIS → 补充或自动提取论文信息 → 表格检索与分类
→ 右侧论文详情 → 连续阅读与批注 → 沉淀术语、框架图和写作佳句
```

## 已实现功能

### 论文库

- 表格展示中英文标题、作者、状态、领域、标签、一句话总结、期刊/会议、日期和链接。
- Category 为单选主领域，Tags 为多选标签；可维护颜色、名称及合并关系。
- 支持内置视图、保存视图、排序、横向滚动、表格密度切换和全文搜索。
- 支持单选、多选、全选论文后批量移入回收站；回收站内可恢复或永久删除。
- 导入 PDF 后根据标题、作者、年份和 DOI 提示疑似重复。

### PDF 阅读与学习

- 默认在应用右侧打开连续下拉式阅读台，并恢复上次阅读页码。
- 按住左 Ctrl 并滚动鼠标滚轮缩放；普通滚轮继续上下阅读。
- 支持文本选择、高亮、下划线、文字批注、手绘、术语收录和写作佳句收录。
- 连续阅读使用 PDF.js `PDFPageView`：画布、文本层、选择区域和批注坐标共用同一页面视口。
- 导出时生成带可见批注的副本。
- 支持从 PDF 框选方法框架图、从剪贴板粘贴图片，并记录页码与坐标。

### 资料沉淀

- 论文详情包含概览、双语摘要、术语/短语和方法框架图。
- 术语条目保存英文词语、中文释义、代表性原句、中文注释、页码和来源批注。
- 写作资料库保存英文原句、中文译文、写作用途、个人改写、标签和回到原文的页码。
- 本地知识树按领域、标签和标题/摘要文本相似度组织节点。

### 导入、搜索与辅助能力

- 支持 PDF、BibTeX 和 RIS 导入；可读取 PDF 文本层并建立页级全文索引。
- 扫描版 PDF 可执行本地 OCR；无文本层状态会明确提示。
- 可选启用 Crossref 在线元数据补全，默认关闭。
- 可接入用户自己的大模型 API，对新导入论文提取双语题目、摘要、总结、术语和框架图候选；结果可编辑后保存。
- 任务与日历完全保存在本地，可关联论文。

## 翻译服务与换机

翻译是可选功能。首次使用术语或佳句翻译时，输入 LibreTranslate 兼容服务地址即可。

- HTTPS 兼容接口：换电脑后重新填写接口地址与 API Key 即可使用。
- 免费本地翻译：新电脑运行 [setup-libretranslate.cmd](scripts/setup-libretranslate.cmd) 一次，随后运行 [start-libretranslate.cmd](scripts/start-libretranslate.cmd)。
- 本地模型存放于 `%LOCALAPPDATA%\PaperNest\LibreTranslate`。
- API Key 保存在 Windows 凭据管理器；换机后重新输入。

## 本地资料库与备份

资料库由用户首次启动时选择位置，包含 `library.db`、受管 PDF、框架图、头像、备份和清单文件。完整备份会保存论文、附件、图片、批注、术语、写作素材、任务和视图；恢复前请关闭正在使用资料库的应用实例。
