# 中文字体

Noto Sans SC 可变字体，版本 2.04，权重 100–900，SIL Open Font License 1.1。

- 上游：[google/fonts · Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)。
- 字体由本机已安装的 `NotoSansSC-VF.ttf`（17,773,244 字节）使用 FontTools 4.67.0 转为 WOFF2，保留全部字形与可变权重轴。
- `NotoSansSC.woff2`：7,783,360 字节；许可见同目录 `OFL-NotoSansSC.txt`。
- CSS 内部字体名为 `PaperNest Sans SC`；应用英文优先使用 Segoe UI，中文使用随包字体。本地加载，无需联网。
